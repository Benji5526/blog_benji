## 1. 웹페이지를 이루는 세 겹

웹페이지는 겉보기에는 하나의 덩어리처럼 보이지만, 서로 다른 문제를 해결하기 위해 태어난 세 가지 축이 겹쳐서 만들어진 구조다. AI에게 개발이나 수정을 지시할 때도 이 세 겹으로 나누어 요청하면 훨씬 정확한 결과를 얻을 수 있다.

- **HTML (구조):** 화면에 무엇이 담기는지(제목, 문단, 버튼 등) 정보의 의미를 정의한다.
- **CSS (표현):** 그 정보가 화면에 어떻게 보일지(색상, 간격, 크기, 반응형 배치 등) 규칙을 정한다.
- **JavaScript (동작):** 사용자가 버튼을 클릭하거나 입력할 때 무엇이 바뀔지 상태와 반응을 제어한다.

## 2. [오늘의 CS] 동기·비동기, 프로세스·스레드·코어

### ① 동기와 비동기 (기다림을 다루는 방식)

- **동기 (Synchronous):** 요청을 보낸 후 작업이 끝날 때까지 멈춰 서서 기다리는 방식이다.
- **비동기 (Asynchronous):** 오래 걸리는 작업을 던져두고 다른 일을 하다가, 완료 알림이 오면 그때 결과를 처리하는 방식이다. (예: 자바스크립트의 비동기 처리와 이벤트 루프)

### ② 프로세스와 스레드 (작업실과 일꾼)

- **프로세스 (Process):** 독립된 메모리 공간(작업실)을 할당받아 실행 중인 프로그램이다. 하나에 문제가 생겨도 다른 곳으로 번지지 않도록 격리해 준다.
- **스레드 (Thread):** 작업실 안에서 실제로 일을 처리하는 논리적 일꾼이다.

### ③ 코어와 시분할 (물리적 일손과 멀티태스킹)

- **코어 (Core):** CPU 안에서 실제로 연산을 수행하는 물리적 일손이다. 멀티코어 구조를 통해 여러 작업을 동시에 처리할 수 있다.
- **시분할 (Time-Sharing):** 실제 실행할 작업은 코어 수보다 훨씬 많지만, 운영체제가 아주 빠른 속도로 작업들을 번갈아가며 실행하여 동시에 실행되는 것처럼 보이게 만든다.
